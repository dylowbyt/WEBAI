Bantuan
Pertanyaan yang sering ditanyakan
Bagaimana cara membuat percakapan baru?
Klik tombol "Percakapan baru" di bagian atas sidebar kiri, atau gunakan ikon hamburger (☰) untuk membuka sidebar.
Bagaimana cara generate gambar?
Klik tab "🎨 Gambar" di bawah input, masukkan API Key Ruxa.ai, lalu ketik deskripsi gambar dan tekan kirim.
Bagaimana cara generate video?
Sama seperti gambar, pilih tab "🎬 Video", masukkan API Key Ruxa.ai, dan deskripsikan video yang diinginkan.
Bagaimana cara upload file?
Klik ikon 📎 di sebelah kiri input chat untuk memilih file dari perangkat kamu. Mendukung teks, PDF, gambar, dan lainnya.
Apa perbedaan paket Free, Basic, Pro, dan Max?
Paket Free gratis dengan limit pesan. Basic (Rp49K) menambah limit dan fitur gambar. Pro (Rp99K) unlimited chat + video. Max (Rp199K) semua fitur tanpa batas.
Bagaimana jika saya mengalami masalah?
Gunakan fitur "Kirim Masukan" di menu Setelan & Bantuan untuk melaporkan bug atau menghubungi tim kami.
