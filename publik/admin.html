Brain Flow Architecture

Bagaimana AIRA memproses setiap permintaan

User Input
↓
public/chat.html → public/js/chat.js
↓ (fetch POST /api/ai/chat)
server.js → api/aiRoute.ts
↓
ai/brain.ts ← OTAK UTAMA
↓
├── ai/intent.ts  (deteksi: chat/image/video/game)
├── ai/memory.ts  (riwayat sesi)
└── ai/planner.ts (multi-step logic)
↓
tools/ (EXECUTOR)
├── chatTool.ts  ← GPT text
├── imageTool.ts ← DALL-E
├── videoTool.ts ← konsep video
└── gameTool.ts  ← game content
↓
Response → Frontend
Aturan Utama
❌ Frontend Tidak ada logic AI atau OpenAI langsung
❌ server.js Tidak ada prompt panjang atau AI decision
❌ tools/ + brain Tidak boleh dicampur
✅ brain.js Hanya memutuskan tool mana yang dipakai
✅ tools/ Hanya eksekusi, tidak ada decision logic
